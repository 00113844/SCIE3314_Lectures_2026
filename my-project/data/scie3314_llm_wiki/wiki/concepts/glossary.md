# Glossary

| Term | Meaning |
| --- | --- |
| CCN | Cereal cyst nematode, *Heterodera avenae*. |
| Decile | A ranked tenth of a historical distribution; decile 5 is the median. |
| Delta T | A temperature/humidity measure used to assess evaporation and spray-drift conditions. |
| GSR | Growing-season rainfall. |
| PBI | Phosphorus buffering index, indicating soil capacity to adsorb phosphorus. |
| Predicta B | Broadacre DNA-based soil test for selected soil-borne pathogens and nematodes. |
| RLN | Root lesion nematode, generally *Pratylenchus* species. |
| SSCM | Site-specific crop management. |
| VMD | Volume median diameter, a droplet-size descriptor. |
| VRT | Variable-rate technology. |
| YFEL / YMB | Youngest fully expanded leaf / youngest mature blade, defined plant-tissue sampling positions. |
