# Cropping system definition and components

A cropping system is the integrated set of crops, soils, climate, machinery, inputs, and
management decisions that together determine what is produced, how sustainably, and at what
profit. Framed at three nested scales: plant, paddock, farm.

## Key points taught (L01)
- Cropping system definition: crops, soils, climate, machinery, management
- Systems thinking as the unit's core skill
- Decisions cascade across the system (stubble retention example)
