# Systems thinking

The unit's core intellectual skill (per README: "the central intellectual skill this unit
builds"). Recognising that a decision made for one reason cascades through the rest of a
cropping system, and that no single component can be optimised in isolation.

## Key points taught (L01)
- System definition: interacting elements forming a unified whole
- System boundaries: inputs, throughputs, outputs
- Feedback loops and equilibrium
- Resilience and tipping points (bifurcation)
- Stocks and flows, subsystems and hierarchy
- The bottleneck principle

## Grounding note
`data/wa_wiki/` has no dedicated document on general systems theory — it's applied WA agronomy,
not systems science. The closest applied grounding is
[[environmental_drivers_and_system_dynamics_of_western_austral]], which frames WA cropping's shift
from sheep-belt to wheat-belt as a systemic transition. Treat that as an illustrative example, not
a source for the theory itself. This is flagged rather than papered over — see
`L01_Introduction_to_Cropping_Systems.yaml` subtopics "Systems Thinking and System" and "What is a
system made from?", which intentionally carry no `wiki_query`.
