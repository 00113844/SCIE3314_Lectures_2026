# Farm records as system memory

Accurate paddock-level record-keeping as the essential memory that makes a cropping system
manageable across multiple years, and the foundation for evidence-based decisions later in the
unit (precision agriculture, financial analysis).

## Key points taught (L01)
- Paddock-level history: yield, herbicide, soil test, fertiliser
- Multi-year decisions require reliable records (rotation, lime, herbicide carryover)
- Digital capture: yield maps, soil and tissue tests
- Consequences of poor records: resistance/plant-back problems, mistimed inputs, undiagnosed
  under-performance
