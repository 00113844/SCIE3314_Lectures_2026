# L06 asset catalogue

Media extracted from the source PowerPoint **`L14 Cereal phenology Growth stages.pptx`**
(48 slides, 57 media files; the file itself sits beside this deck in `../`). Filenames are
the original PPTX media names and are deliberately **not** renamed, so that any slide can be
traced back to the source deck.

> **Corrected 2026-08-18.** This file previously named `L17 L18 L19 L20 Barley agronomy.pptx`
> as the source. That is wrong. The barley deck carries a completely different media set — 78
> files, different extensions, including `.emf` and `.wmf` — and none of its byte sizes match
> anything here. The images below all match the phenology deck exactly (for example `image1.jpg`
> at 157,406 bytes and `image18.JPG` at 63,352 bytes). The barley deck is the source for the
> deck's *text* content in Part 5 (grain quality, malting specifications, screenings, brightness)
> and for the G × E × M variance table, but not for any image in this folder.

Most of the JPG plates below are reproduced in the source deck from the **DPIRD/GRDC
*Wheat Book: Principles and Practice*** (chapters 2 and 3), which is what `index.html` now cites.

`✓` = used in `../index.html`.

> **Note on the two `_rotated` files.** `image56.png` and `image57.png` were stored in the
> PowerPoint rotated 90° counter-clockwise (portrait files whose content reads bottom-to-top).
> They were rotated back and re-encoded rather than corrected with a CSS `transform`, because the
> transform approach needs a fixed-height wrapper whose geometry silently breaks whenever the
> surrounding layout changes. The originals are kept for provenance.
